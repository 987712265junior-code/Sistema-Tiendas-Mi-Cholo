# Sistema Tiendas Mi Cholo

## Descripción
Sistema de gestión de ventas e inventario desarrollado en Python para el curso de Fundamentos de Programación de la UPN.

## Funcionalidades
- Registro y validación de productos.
- Registro de ventas y actualización del stock.
- Búsqueda secuencial y ordenamiento burbuja.
- Consulta de inventario e ingresos.
- Almacenamiento de datos mediante archivos CSV.
